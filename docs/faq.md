# FAQ - Skills Marketplace

## General Questions

**Q: What is a skill?**
A: A reusable Claude Code workflow that Dynamic Group has built for a specific task.

**Q: How do I install a skill?**
A: See [INSTALLATION.md](../INSTALLATION.md) for step-by-step instructions.

**Q: How do I use an installed skill?**
A: Type the skill name as a slash command (e.g., `/construction-timeline`).

**Q: Can I modify a skill?**
A: Yes – local edits are fine for your own use. Share improvements via pull request.

## Creating Skills

**Q: How do I create a new skill?**
A: See [docs/skill-template.md](skill-template.md) and [CONTRIBUTING.md](../CONTRIBUTING.md).

**Q: How do I test my skill?**
A: Copy it to your `~/.claude/skills/` folder and use it in Claude Code.

**Q: How do I submit my skill?**
A: Follow [CONTRIBUTING.md](../CONTRIBUTING.md) and create a pull request.

## Troubleshooting

**Q: My skill isn't showing up in Claude Code**
A: Check that you copied the skill folder to `~/.claude/skills/` and reloaded Claude Code.

**Q: I get an error when using a skill**
A: Check the SKILL.md for YAML syntax errors and review the README for usage examples.
