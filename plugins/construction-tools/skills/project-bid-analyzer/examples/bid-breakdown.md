# Example: FEMA Temporary Housing RFQ

## Scenario
100-unit temporary modular housing from FEMA disaster recovery program

## Input
```
/project-bid-analyzer

RFQ Summary:
- 100 modular units, 1-year occupancy
- Budget: $12 million ($120K/unit)
- Timeline: 9 months to occupancy-ready
- Prevailing wage required
- Performance bond: 10%
- Liquidated damages: $2,500/day
```

## Analysis
- **Budget Fit:** Reasonable ($120K/unit for modular + prevailing wage)
- **Schedule Risk:** ⚠️ AGGRESSIVE - tight with high penalties
- **Compliance:** Prevailing wage significantly impacts costs
- **Viability:** PURSUE with caution

**Key Risks:**
- Liquidated damages = $75K/month penalty
- Zero schedule buffer
- Must confirm team capacity upfront
