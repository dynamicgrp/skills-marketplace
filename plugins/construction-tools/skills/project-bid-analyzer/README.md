# Project Bid Analyzer

Break down RFQs, RFPs, and bid requests. Identify scope gaps, flag risks, and generate structured response checklists.

## Overview

This skill helps business development and proposal teams quickly analyze construction bid opportunities. It identifies what's being asked, what might be missing, what risks exist, and whether a project is a good fit for Dynamic Group.

**Perfect for:**
- Rapid bid opportunity assessment
- Identifying scope ambiguities and gaps
- Flagging compliance or contractual risks
- Go/no-go bidding decisions
- RFI (Request for Information) planning

## When to Use

✅ Use when:
- You receive an RFQ/RFP and need quick assessment
- You need to decide whether to pursue a bid
- You want to identify clarifying questions before bidding
- You need to flag risks to management
- You're evaluating multiple bids and prioritizing effort

## How to Use

### 1. Activate the Skill
```bash
/project-bid-analyzer
```

### 2. Provide Bid Document
Copy and paste the RFQ, RFP, or bid summary.

### 3. Provide Context
Tell Claude:
- Project location and type
- Customer type (gov, private, nonprofit)
- Your team's relevant experience
- Any capacity constraints

### 4. Get Analysis
Claude will provide:
- **Executive Summary** - Viability assessment
- **Scope Breakdown** - What's requested
- **Risk Assessment** - Budget, schedule, compliance, contractual
- **Response Checklist** - Items needed to respond
- **Next Steps** - Recommended actions
