# Construction Timeline Analyzer

Analyze construction schedules, identify critical path bottlenecks, and generate practical acceleration recommendations.

## Overview

This skill helps Dynamic Group teams analyze construction project timelines using Critical Path Method (CPM) analysis. It identifies which activities are driving project completion, spots bottlenecks, and recommends acceleration strategies.

**Perfect for:**
- Disaster recovery housing projects with tight deadlines
- Schedule acceleration and compression analysis
- Identifying critical path activities and float
- Assessing schedule risk and contingency
- Modular construction coordination and sequencing

## When to Use

Use this skill when you need to:
- ✅ Analyze a project schedule for bottlenecks
- ✅ Identify the critical path and activities with zero float
- ✅ Generate schedule acceleration recommendations
- ✅ Assess the feasibility of compressing a timeline
- ✅ Understand dependencies and sequencing impacts

## How to Use

### Step 1: Activate the Skill
```bash
/construction-timeline
```

### Step 2: Provide Project Information
- Project name and type (e.g., "50-unit disaster recovery housing, Florida")
- Key constraints (fixed completion date, permitting delays, etc.)

### Step 3: Provide Schedule Data
Share your project schedule:
- Activity names and durations
- Dependencies (which activities must happen first)
- Milestone dates (hard deadlines)
- Resource constraints

### Step 4: Get Analysis
Claude will provide:
- **Critical Path**: Which activities determine project finish date
- **Bottleneck Analysis**: What's slowing the project down
- **Acceleration Options**: Ranked strategies with impacts and risks
- **Recommendations**: Top action items to compress schedule
